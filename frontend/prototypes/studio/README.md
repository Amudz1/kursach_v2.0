# Макет «Студия диалогов Budz»

Запустите `npm run dev` из папки `frontend` и откройте `/prototypes/studio/` по адресу локального сервера Vite.

| Параметр URL | Значения |
| --- | --- |
| `screen` | `start`, `chat`, `appearance` |
| `mode` | `light`, `dark` |
| `history=empty` | Первый экран при пустой истории |
| `at=plan` | Переход к примеру сохранённого ответа в открытой беседе |
| `draft=1` | «Оформление» с изменёнными настройками и открытой панелью сохранения |

Отправка сообщения показывает пример ответа. Закладки и настройки действуют до перезагрузки макета. Макет использует общие компоненты, шрифты и рендерер Markdown. Для просмотра достаточно Vite.

Проверка типов макета из папки `frontend` выполняется командой `npx vue-tsc --noEmit -p prototypes/studio/tsconfig.json`.
