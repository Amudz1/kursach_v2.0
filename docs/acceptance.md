## Результаты итогового прогона

- xUnit — 13 модульных и 4 интеграционных теста прошли. Интеграционные сценарии использовали отдельный PostgreSQL 16. Сверка EF Core не выявила изменений модели вне миграции.
- Покрытие строк ключевой логики составило 95,71 % по объединённым отчётам Cobertura. В расчёт входят сборка контекста, квоты, отзывы, валидаторы аккаунта и обработчики профиля. Покрытие всего слоя Application составило 55,75 %.
- Сборки .NET и Vue завершились успешно. Docker Compose поднял PostgreSQL, API и Nginx. Проверка через Nginx вернула `200 Healthy`, открылся OpenAPI v1.
- Playwright проверил регистрацию, онбординг, поток, остановку, регенерацию, оценки, память, персоны, тариф, личную статистику и удаление тестового аккаунта. Отдельно проверена загрузка разделов администрирования при ширине 360 px. Первый фрагмент демо-ответа уложился в три секунды.

## Условия проверки

- Ответы и фоновые операции проверялись с демонстрационным провайдером. Для реального вызова OpenRouter нужен ключ. Поведение конкретной модели и задержка её первого токена зависят от внешнего сервиса и отдельно не измерялись.
- PDF читается по текстовому слою. Распознавание сканов не входит в реализованный сценарий. Изображения проверялись по выбору совместимой модели и подготовке запроса. Сетевой тест vision выполняется с ключом OpenRouter.
- Приложение развёрнуто одним экземпляром API. Файлы хранятся в приватном томе. Сессии используют HttpOnly-cookie и access-токен в памяти Vue.
- Переезд использует новую схему PostgreSQL и демонстрационные данные. Исторические данные Laravel не копировались. Исходная ревизия доступна в истории Git.
