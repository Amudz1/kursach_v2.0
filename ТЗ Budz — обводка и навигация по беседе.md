# ТЗ на обводку сообщений и навигацию по беседе в Budz

Сделать ленту визуально спокойнее и дать пользователю способы вернуться к нужному месту в длинном чате. Настройки оформления охватывают шесть вариантов контура. Навигация объединяет закладки, оглавление, поиск по тексту беседы и карточку «Продолжить».

ТЗ опирается на версию «Студии диалогов» с четырьмя формами обводки. Оно уточняет волнистый контур и дополняет сценарии закладок, оглавления и восстановления позиции чтения.

## 1. Обводка сообщений

В разделе **«Оформление → Диалоги → Обводка сообщений»** доступны следующие варианты.

| Вариант | Отображение |
| --- | --- |
| Прямоугольная | Тонкая рамка с небольшим радиусом углов. |
| Волнистая | Мелкие плавные волны по верхнему и нижнему краям. Боковые линии мягко соединяются с краями. |
| Скруглённая | Тонкая рамка с заметно округлыми углами. |
| Овальная | Короткие сообщения имеют форму капсулы. У длинных сообщений сохраняются прямые участки по бокам и достаточные отступы для текста. |
| Без обводки | Ответы Budz лежат на общем фоне, а свои сообщения выделены лёгкой заливкой. |
| Боковая линия | Тонкая вертикальная полоса слева от текста сообщения в приглушённом акцентном цвете темы. |

Для мелкой волны взять **28 CSS px между соседними вершинами** вместо текущих 48 px. Ориентир перепада от вершины до впадины — 3–4 CSS px, толщины штриха — 1 CSS px. Дуги должны образовывать непрерывную мягкую линию. Цвет берётся из токенов темы и корректируется по светлому и тёмному фону. В высококонтрастных режимах контур различим, а метки автора и действия читаются независимо от его формы.

Мелкая волна используется по умолчанию в «Студии». Явно сохранённая форма имеет приоритет над пресетом. Для других пресетов применяются их действующие значения по умолчанию. Настройка сразу применяется в предпросмотре, «Отменить» возвращает сохранённый вариант, а «Сохранить» записывает выбор в аккаунт. Экспорт и импорт темы включают две новые формы. Старый файл темы с любым из четырёх прежних вариантов открывается корректно.

Форма применяется к сообщениям обоих авторов и сочетается с режимами «Лента», «Карточки» и «Пузыри». Названия авторов, кнопки действий, вложения и состояния генерации остаются различимыми. Длинные строки кода и таблицы прокручиваются внутри своих блоков.

## 2. Закладки и оглавление

- У сохранённого ответа Budz в обычной беседе действие «Добавить закладку» ставит янтарную точку. Повторное действие «Убрать закладку» снимает её. Состояние кнопки доступно с клавиатуры, мыши и сенсорного экрана. Закладка привязана к идентификатору сообщения и доступна в том же аккаунте с другого устройства.
- Кнопка «Оглавление» открывает боковую панель на компьютере и нижнюю панель на телефоне. В ней два раздела — «Вопросы» в порядке беседы и «Закладки». Пункты показывают короткие фрагменты исходных сообщений. В пустом разделе закладок отображается понятная подсказка.
- Выбор пункта открывает нужную часть истории, показывает сообщение в области чтения и выделяет его. Это работает и для сообщений, которые ещё не подгружены. При отключённом движении переход происходит без плавной прокрутки. Если панель закрыли клавишей Escape или кнопкой, фокус возвращается к её кнопке открытия.
- Повторное добавление одного сообщения даёт одну закладку. При удалении сообщения или беседы связанные закладки исчезают из списка. Операции с закладками проверяют доступ к аккаунту, беседе и сообщению. Для временных бесед применяется действующий срок хранения истории, закладки в них недоступны.

## 3. Поиск внутри текущей беседы

- Действие «Поиск по беседе» открывает поиск в шапке или меню открытой беседы. Текст сопоставляется без учёта регистра по вопросам пользователя и ответам Budz, включая содержимое блоков кода. Поиск охватывает все доступные сохранённые сообщения текущей беседы, включая сообщения за пределами загруженной страницы.
- Результат показывает автора, короткий фрагмент с выделенным совпадением и переход к сообщению. Если совпадений несколько, пользователь может перейти к предыдущему или следующему. При выборе результата загружается нужный участок ленты. Пустой запрос, отсутствие результатов и ошибка загрузки имеют отдельные состояния.
- Существующий поиск в истории по-прежнему открывает список подходящих бесед. Поиск внутри открытой беседы работает по её идентификатору и использует те же проверки доступа, что и чтение сообщений. Если временная беседа доступна, поиск ограничен её текущим сроком хранения.

## 4. Продолжение чтения

- Позиция чтения хранится на текущем устройстве отдельно для аккаунта и беседы. Позиция привязана к видимому сообщению и смещению внутри него. Запись выполняется с ограниченной частотой при прокрутке. Новые части ответа не сдвигают пользователя, пока он читает более ранний фрагмент.
- На первом экране карточка «Продолжить» показывает одну доступную обычную беседу, её название, проект при наличии и короткий фрагмент сохранённого сообщения. Внутри проекта карточка выбирается среди его бесед. При первом просмотре возможен переход к последнему сообщению последней доступной беседы.
- Карточка восстанавливает сохранённое место, догружая нужное сообщение при необходимости. Если оно удалено, открывается ближайшее доступное сообщение или конец беседы. При пустой истории, а также когда подходящих бесед нет, остаются поле ввода и примеры запросов. Позиции временных бесед не сохраняются.

## 5. Реализация

- Переиспользовать CSS-токены, общие стили контура, модуль оформления, предпросмотр и действующий Markdown-рендерер. Допустимые значения обводки согласовать в клиентской и серверной валидации. Для старых настроек с отсутствующим полем использовать значение выбранного пресета.
- Закладки хранить как пользовательские ссылки на сообщения. Для переходов из поиска, оглавления и карточки «Продолжить» использовать общий механизм загрузки участка истории и позиционирования по идентификатору сообщения. Выдавать списки и результаты поиска порциями по мере необходимости.
- Оглавление, фрагменты и совпадения строить по сохранённому тексту. Для этих функций требуется **0 дополнительных вызовов модели**. Подсветка применяется при отображении и сохраняет исходный Markdown, который пользователь копирует или экспортирует.

## 6. Этапы и приёмка

1. Обновить волнистую обводку, добавить два варианта и проверить сохранение и предпросмотр.
2. Добавить общий переход к сообщению, закладки и оглавление.
3. Добавить поиск внутри беседы и карточку «Продолжить». Прогнать сценарии обычной, длинной и временной беседы. Показать итоговые скриншоты.

| Сценарий | Условие приёмки |
| --- | --- |
| Мелкая волна | Волны с шагом около 28 px визуально мельче текущих. Штрих тонкий и плавный на коротком сообщении и длинном ответе в обеих темах. |
| Переключение формы | Все шесть вариантов видны в предпросмотре. Отмена, сохранение, перезагрузка и импорт старого и нового JSON дают ожидаемую форму. |
| Закладки | Закладка открывает точный ответ, даже если он ещё не загружен. Она доступна с другого устройства, удаляется по команде и исчезает при удалении сообщения. |
| Оглавление | Переход к вопросу и закладке работает с клавиатуры и касанием. На телефоне панель открывается снизу, при закрытии восстанавливается фокус. |
| Поиск | Фраза из раннего сообщения и строка кода находятся без предварительной прокрутки. Можно перейти между несколькими совпадениями. Чужая беседа не выдаёт результаты. |
| Возврат к чтению | После ухода из чата и перезагрузки карточка возвращает к сохранённому фрагменту. Проверены пустая история, проект и удалённое сообщение. |
| Совместимость | На ширине от 320 px до 1440 px страница не получает горизонтальную прокрутку. Проверены обе темы, высокий контраст, отключённое движение и текущие сценарии отправки, копирования и экспорта. |
